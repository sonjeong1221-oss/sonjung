## 2026-11-13 — 2D 평면도 가구 아이콘 겹침(디클러터) 수정

**상태**: 코드 작성 완료, 사용자 로컬 Play 모드 검증 대기 중

**문제**: 외부지원팀실 평면도 화면에서 "도서서가"와 "데스크탑 PC(T자, 2대) + 의자석" 아이콘이
서로 겹쳐서 라벨이 뭉쳐 보임. 원인 확인: 3D 미터 좌표를 방 크기로 정규화해 바로 2D 픽셀
위치로 썼는데, 작은 방은 가구 사이 3D 거리가 가까운 반면 2D 아이콘은 고정 픽셀 크기라
방이 작을수록 아이콘 간 실제 간격(픽셀)이 아이콘 자체 크기보다 작아지는 경우가 생김
(외부지원팀실: 두 아이콘 중심이 44px 떨어져 있는데 반쪽 너비 합이 105px 필요).

**수정**: `RoomFloorPlanUI.cs` — 가구 아이콘을 바로 만들지 않고, 먼저 전부의 "원하는 픽셀
위치"를 계산해 목록(`IconPlan`)으로 모아둔 뒤, 겹치는 쌍을 반복적으로 서로 밀어내는 간단한
AABB 디클러터(`Declutter`)를 돌리고, 그 결과 위치로만 실제 아이콘을 생성하도록 2단계로
재구성(`BuildIcons`/`BuildIcon(IconPlan)`). 세로 여유에는 라벨 높이도 포함해서 라벨끼리도
안 붙게 처리. 아이콘 앵커 방식도 정규화 좌표 포인트 앵커 대신 스테이지 중앙 기준 픽셀
오프셋(`anchoredPosition`)으로 바꿔서 디클러터 결과를 그대로 쓸 수 있게 함.

  `HubUI`의 정규화 좌표 평면도 방식, `QnaPanel`의 질문-답변 로직 — 전부 3D와 무관해서 그대로 씀.
- **더 이상 안 씀(삭제는 안 함)**: `FirstPersonController`, `InteractionSystem`,
  `IInteractable`, `SimpleInteractable`, `FacilityController`의 3D 그레이박스/Kenney 가구
  스폰 로직 전체 — `Bootstrap.cs`에서 더 이상 생성하지 않도록만 변경(원칙 #2 고려해 파일

- `CLAUDE.md` 갱신: "1인칭 3D" 전제를 "2D 평면도" 전제로 바꾸고 이 방향 전환 사실을

| Sofa | loungeSofa | |
